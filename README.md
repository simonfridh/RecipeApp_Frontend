1. Install Node.js (https://nodejs.org/en)
   
2. Set up and start the Backend server (https://github.com/simonfridh/RecipeApp_Backend)
   
3. If you have hosted the backend server on a URL that is NOT ```http://127.0.0.1:8000``` open ```.env.local``` and change the ```BACKEND_URL``` to the URL you are using.
   
4. Open a terminal and navigate to the project folder (RecipeApp_Frontend/)
   
5. Run the following command to install dependencies:
    ```bash
    npm install
    ```
6. Run the following command to start the server:
    ```bash
    npm run dev
    ```

7. Open http://localhost:3000 in any browser. 
    * The website will be hosted on your local computer as a development server, you can access the website from other devices on your local network through ```your_private_ip_address:3000``` in a browser.
